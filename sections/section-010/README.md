# Build and run Backstage projects locally

This section covers build and run Backstage projects locally. It develops local Projects, Development Servers And Production Builds through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains can include intermediate checkpoints before the final review.

## Learning Outcomes

- Explain the responsibilities of the app and backend workspaces.
- Distinguish a development server from a production artifact.
- Locate startup failures by dependency, configuration and process boundaries.
