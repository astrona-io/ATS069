# Understand local development workflows

This section covers understand local development workflows. It develops changes, Workspace Feedback And Reviewable Development through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains can include intermediate checkpoints before the final review.

## Learning Outcomes

- Trace a source change through the relevant workspace and checks.
- Explain why fast feedback needs both type and behavior checks.
- Distinguish local overrides from committed project configuration.
