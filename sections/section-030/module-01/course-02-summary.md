# Summary

TypeScript expresses and checks source contracts, while JavaScript and packaged assets execute at runtime. A workspace build must account for imports, declarations and generated artifacts in dependency order. Successful type checking cannot establish network reachability, authorization or truthful external data. Diagnose the actual boundary: an incompatible source type, missing build output and a failed runtime dependency require different repairs.
