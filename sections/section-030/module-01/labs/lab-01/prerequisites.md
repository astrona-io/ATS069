# Prerequisites

- The `astrona` command-line tool, installed and working (`astrona check` passes).
- About 4 GiB of free memory and 20 GiB of free disk space for the virtual machine, and internet access when it starts.
- You can read a short TypeScript function and a `tsconfig.json` file, and you can edit a file in a terminal.

The lab starts an Ubuntu 24.04 virtual machine with Node.js 22 and the `tsc` compiler. The workspace is in `/opt/portal`.
