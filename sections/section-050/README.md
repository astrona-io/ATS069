# Use Docker to build a container image of a Backstage project

This section covers use Docker to build a container image of a Backstage project. It develops container Artifacts, Build Inputs And Runtime Responsibilities through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains can include intermediate checkpoints before the final review.

## Learning Outcomes

- Describe the files and dependencies a Backstage container needs.
- Explain host-build and multi-stage packaging tradeoffs.
- Distinguish a built image from a correctly configured deployment.
